
# Hospital Appointment Operations Analysis

## Project Overview
This project analyses hospital appointment records using Python. It focuses on appointment attendance, waiting times, department-wise appointments, SMS reminders and consultation fees.

The main aim is to understand the appointment data and identify areas where hospital operations may be improved.

## Objectives
- Analyse total appointments and attendance status.
- Find missing values and duplicate records.
- Calculate department-wise average waiting time.
- Compare no-show percentages across departments.
- Study the effect of SMS reminders on attendance.
- Analyse consultation fees.
- Identify unusually long waiting times.
- Provide suggestions based on the analysis.

## Technologies Used
- Python
- Pandas
- NumPy
- Visual Studio Code

The dataset contains 100 sample appointment records with the following columns:

- Appointment_ID
- Appointment_Date
- Department
- Appointment_Type
- Attendance_Status
- Waiting_Time_Minutes
- SMS_Reminder
- Consultation_Fee

**Note:** This is sample educational data and does not contain actual hospital or patient records.
